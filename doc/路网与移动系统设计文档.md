# 🛠️ 独立六边形路网编辑器 (`/editor`) 与寻路系统设计方案

本文档为 **AI 酒馆奇幻 RPG** 中**独立六边形路网编辑器工具**（访问路由 `/editor`）的技术设计方案。

---

## 🎨 1. 路由与架构规划

我们将路网编辑器设计为独立且纯粹的开发工具页面，通过 `vue-router` 进行页面路由隔离：

* `http://localhost:5173/#/`：游戏主界面。
* `http://localhost:5173/#/editor`：独立六边形路网编辑器。

```
apps/web/src/
├── router/
│   └── index.ts                 # Vue Router 路由定义 (/ 和 /editor)
├── types/
│   └── hexMap.ts                # 六边形单元格、网格配置、A* 路径节点定义
├── engine/
│   ├── hexMath.ts               # 六边形像素坐标 (x,y) 与轴向坐标 (q,r) 转换
│   ├── hexPathfinding.ts        # 6 方向 Hex A* 最短路径算法
│   └── pixiHexEngine.ts         # PixiJS v8 蜂窝渲染、刷涂与试走平滑滑动引擎
└── views/
    ├── HomeView.vue             # 游戏主页
    └── RoadNetworkEditor.vue    # 独立路网编辑器路由页面
```

## 🛠️ 2. 编辑器界面布局 (`RoadNetworkEditor.vue`)

编辑器分为 **顶部控制栏 (Vue 3 Glass Header)** 和 **中间 PixiJS v8 六边形画布** 两个区域：

```
+---------------------------------------------------------------------------------------------------+
| [ Top Header ] 📁上传背景图 | 离散度Slider | 🖌️涂色 🧼橡皮 🧹清空 | 🧪试走测试 (WASD+鼠标) | 💾导出 JSON |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|                                                                                                   |
|                           [ PixiJS v8 Canvas: Background + Hex Grid Overlay ]                      |
|                               (支持鼠标拖拽刷涂通行区域、试走小人平滑移动)                           |
|                                                                                                   |
|                                                                                                   |
+---------------------------------------------------------------------------------------------------+
```

### 控制栏功能明细：
1. **📁 上传背景图**：从本地电脑选择任意分辨率与尺寸的场景插画/大地图，PixiJS 自动自适应居中展现。
2. **六边形粒度 Slider**：实时调整六边形半径 $R$（如 20px ~ 60px），自适应填充全图。
3. **刷子模式选择**：
   * `🖌️ 通行涂色 (Walkable)`：鼠标按住拖拽连刷涂成发光绿/深色（标记为可通行）。
   * `🧼 障碍擦除 (Blocked)`：鼠标长按擦除还原为透明/障碍。
   * `🧹 清空所有`：重置当前图层。
4. **🧪 试走测试**：一键开启/关闭试走测试，在刷好的区域用 WASD 或鼠标点击测试 A* 寻路与平滑移动效果。
5. **💾 导出/载入 JSON**：下载配置 JSON（形如 `tavern_map_hex.json`），或读取已有配置文件恢复网格。

## 📐 3. 六边形数学与 A* 寻路公式

1. **轴向坐标 (Axial Coordinates $(q, r)$)**：
   六边形相邻节点坐标偏移为：
   $$\text{Neighbors} = [(+1, 0), (+1, -1), (0, -1), (-1, 0), (-1, +1), (0, +1)]$$
2. **Hex Distance 曼哈顿距离**：
   $$\text{dist}(A, B) = \frac{|q_A - q_B| + |r_A - r_B| + |(q_A + r_A) - (q_B + r_B)|}{2}$$
3. **平滑移动 (Lerp Smoothing)**：
   小人沿 A* 计算出的路径点依次做匀速线性插值 (`lerp`) 移动，实现顺畅无卡顿的行走效果。

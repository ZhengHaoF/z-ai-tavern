# ⚔️ AI 酒馆奇幻 RPG — 视觉设计与 UI 布局架构文档 (Visual Design & Layout Spec)

本文档为 **AI 酒馆奇幻 RPG 探索游戏** 的视觉设计规范、界面布局架构与交互细节文档，致力于打造**冷峻、写实、金属感厚重且古朴华贵**的 AAA 级韩系暗黑 RPG 沉浸体验。

---

## 🎨 1. 设计理念与视觉风格 (Design Philosophy)

* **视觉风格定位**：**韩式暗黑写实风 (Korean Dark Fantasy Realism UI)**。
* **设计标杆**：《失落的方舟 Lost Ark》、《黑色沙漠 Black Desert》、《天堂W Lineage W》、《Night Crows》、《匹诺曹的谎言 Lies of P》。
* **视觉核心词**：`玄武黑铁` · `锻造倒角` · `鎏金箔线` · `符文光彩` · `Cinzel 硬朗衬线` · `角落金扣 (Corner Ornaments)`。
* **设计原则**：
  1. **零整体滚动沉浸视口**：界面高度固定为 `100vh`，无冗余网页滚动条，确保玩家时刻置身于沉浸游戏视口中。
  2. **暗铁沉降与雕花质感 (Dark Metal Slab)**：面板、槽位与按键采用黑曜石/玄武岩渐变底色，搭配双重内阴影沉淀与镔金金属包边。
  3. **金箔字体与大字距 (Gold Foil & Serif Typography)**：标题采用 `Cinzel` 衬线大写字体与金箔渐变文本（`linear-gradient(180deg, #ffffff, #fef08a, #c5a059, #8c6827)`），字距拉开 `0.08em - 0.12em`，营造冷峻中世纪大魔幻氛围。
  4. **符文流光与战术阵法 (Rune Array Grid & Trail)**：画布中的节点、网格线与寻路 Path 采用冰蓝能量 (`#38bdf8`) 与琥珀镔金 (`#e6c280`) 相互交织的写实法阵纹理。

## 🏛️ 3. 组件级 UI 规范 (Component Specifications)

### 3.1 暗黑黑铁面板 (`.korean-dark-slab`)
- **面板背景**: `linear-gradient(180deg, rgba(22, 22, 30, 0.92) 0%, rgba(12, 12, 17, 0.95) 100%)`
- **边框与阴影**: `1px solid rgba(197, 160, 89, 0.32)` + `box-shadow: inset 0 0 20px rgba(0,0,0,0.8), inset 0 1px 0 rgba(255,255,255,0.12), 0 16px 40px rgba(0,0,0,0.7)`
- **角落金扣 (Corner Ornaments)**: 4 角附带 `.corner-accent` (6x6px 暗金直角框扣)。

### 3.2 暗铁锻造按键 (`.korean-btn-metal` & `.korean-btn-gold`)
- **标准黑铁按键**: 暗铁渐变底色，带镔金细框，悬停呈现亮金发光边 (`box-shadow: 0 0 14px rgba(226,194,128,0.35)`)。
- **黄金特优按键**: 三重黄金渐变 (`#c5a059` -> `#9a7432` -> `#684a1a`)，发光气场沉稳。
- **触感回弹**: 按压时执行 `transform: translateY(1px)` 与 `box-shadow: inset 0 2px 6px rgba(0,0,0,0.8)` 沉重压下反馈。

### 3.3 刻字槽位分段选择器 (`.korean-segmented-slot`)
- 沉陷式黑铁槽位 (`background: rgba(8, 8, 12, 0.9)`), 内部嵌带 `.korean-slot-item`。
- 选中项激活为凸起暗金符文块，具备浓厚写实 RPG 开关感。

### 3.4 战术信息罗盘指示器 (`.korean-compass-panel`)
- 底部悬浮信息胶囊重构为写实战术罗盘外观，搭配金属切角与分段金线。

### 3.5 PixiJS 六边形画布渲染
- **背景画布框**: `0x0c0c14` 暗沉玄武岩衬底，带金线边框。
- **通行打标 Hex**: 黄金古脉冲填充 (`0xc5a059`, alpha: 0.32) + 金线边框 (`0xe6c280`, alpha: 0.85)。
- **演练路线 Path**: 冰蓝能量线条 (`0x38bdf8`) + 金色核心连线 (`0xe6c280`) 与符文 Waypoints 点阵。

## 📐 4. 首页 UI 布局架构与模块摆放 (Homepage Layout & Module Placement)

首页采用 **“上方主探索与对话视窗 (双栏 60% / 40%) + 底部固定沉浸状态 HUD Dock (72px)”** 的经典 RPG 高保真结构。

```
+---------------------------------------------------------------------------------------------------+
| [ 上方主探索与对话视窗区域: calc(100vh - 84px) ]                                                  |
| +-------------------------------------------------------+---------------------------------------+ |
| | [ 模块 B ] 左侧主探索视窗 (60% 宽度)                  | [ 模块 C ] 右侧 AI 酒馆控制台         | |
| | ----------------------------------------------------- | (40% 宽度)                            | |
| | B1. 顶部模式切页 (🗺️ 2D世界大地图 / 🖼️ AI场景剧照)   | C1. 当前对话 NPC 档案 Banner         | |
| | B2. 主渲染视窗 (PixiJS v8 节点地图 或 AI 插画背景)    | C2. 打字机流式聊天视窗 (Chat Logs)    | |
| | B3. 场景浮动交互热点 (Hotspot Pins)                 | C3. 快捷回复 Chip 引导栏              | |
| | B4. 底部环境叙事微条 (Environment Status Bar)       | C4. 用户输入框与黄金发送按钮         | |
| +-------------------------------------------------------+---------------------------------------+ |
+---------------------------------------------------------------------------------------------------+
| [ 模块 A ] 底部固定沉浸玩家 HUD Dock (置底, 高度 72px)                                             |
| (玩家头像、血/蓝条、金币、属性胶囊、🎒背包 / 📜任务 / 🎲检定 / ⚙️设置/角色卡 按钮组)                  |
+---------------------------------------------------------------------------------------------------+
```
